بدلًا من ذلك، أضيفت ثلاثة مسارات عملية: بوابة إدخال واضحة تمنع البيانات غير المصرح بها أو المحمية، ملف استرداد يفعّل خيارات التصدير الموجودة بالفعل لحفظ العلاقات بين الأصول، وتقرير تشخيص بعد الاستيراد يجرد البيانات التي قرأها المستورد العادي فقط.

## 2. ما تم تنفيذه فعليًا

### 2.1 تطبيق Premium منفصل

أضيف مشروع تنفيذي جديد باسم `AssetRipper.GUI.Premium`. عند تشغيله يضبط هوية الإصدار إلى Premium، ويطلب من المستخدم إضافة الوسيط التالي:

```text
--premium-authorized
```

هذا الوسيط **ليس مفتاحًا تقنيًا لفك ملفات أو حماية**؛ بل هو تصريح من المستخدم بأنه مخول لمعالجة البيانات النصية/غير المشفرة التي اختارها. إذا غاب التصريح، يمنع التطبيق عملية التحميل قبل أن تبدأ.

### 2.2 سياسة إدخال آمن

أضيفت وحدة `PremiumInputPolicy` داخل مشروع مستقل. تقبل هذه السياسة الأنواع النصية القياسية فقط: Unity Bundle، الملف المتسلسل Serialized File، Resource Stream، مصدر SpriteAtlas، وتدفق AudioClip. وتعيد نتيجة منظمة تحتوي رمزًا ورسالة بدل محاولة تخمين طريقة قراءة مدخل غير مدعوم.

| حالة الإدخال | السلوك | رمز النتيجة |
| --- | --- | --- |
| تصريح المستخدم غير موجود | رفض قبل التحميل | `authorization-required` |
| ملف Unity نصي ومصرح به | قبول للمستورد العادي | `plaintext-supported` |
| مؤشر أن الإدخال مشفر | رفض | `encrypted-input-not-supported` |
| تفريغ ذاكرة وقت التشغيل | رفض | `runtime-memory-not-supported` |
| حاوية افتراضية خاصة | رفض | `custom-vfs-not-supported` |
| صيغة غير معروفة | رفض | `unsupported-format` |

### 2.3 ملف الاسترداد عالي الدقة

أضيف `PremiumRecoveryProfile`، وهو يضبط **خيارات تصدير موجودة ومثبتة** قبل الاستيراد المصرح به. لا يكتب Parser جديدًا لتجاوز صيغة مجهولة ولا يخترع بيانات مفقودة. الهدف هو المحافظة على علاقات الأصول القابلة للقراءة كي تكون نتيجة التصدير أكثر ترتيبًا وقابلة للفحص.

| الإعداد الفعلي | القيمة المطبقة | الغرض |
| --- | --- | --- |
| Prefab outlining | مفعّل | المحافظة على بنية Prefab القابلة للتصدير |
| Static mesh separation | معطّل | عدم تفكيك Mesh الساكنة بصورة تفقد علاقتها الأصلية |
| Asset deduplication | معطّل | عدم دمج أصول متشابهة قد تكون مراجع مستقلة |
| Bundled asset mode | `DirectExport` | تصدير مباشر للحزم القابلة للقراءة |
| نموذج التصدير | FBX | إخراج النماذج إلى مسار FBX الموجود في البرنامج |
| الصور | PNG | مسار إخراج واضح للصور القابلة للقراءة |
| Sprite mode | YAML | الاحتفاظ بوصف Sprite ضمن بنية مشروع Unity |
| Audio | الصيغة الافتراضية المدعومة | عدم فرض تحويل غير موثوق |
| امتداد Texture الأصلي | مفضل | عدم فقد معلومة صيغة المصدر عندما تكون متاحة |
| Unreadable assets | لا تصدّر | عدم خلق بدائل مزيفة لمحتوى لا يمكن قراءته |

### 2.4 تقرير تشخيص ما بعد الاستيراد

أضيفت وحدة `PremiumImportDiagnostics` ونقطة JSON في الواجهة على العنوان:

```text
/Assets/PremiumDiagnostics
```

لا يقرأ التقرير إلا ما حمّله المستورد العادي بنجاح. ويعرض إصدار Unity الذي جرى التعرف عليه، ومسارات الإدخال، وعدد Asset Collections وResource Files وFailed Files، وعدد الأصول المصنفة، وأكبر 32 فئة أصول. كما يضع أولوية فحص لعائلات Mesh وSkinnedMeshRenderer وSpriteAtlas وTexture2D وAnimationClip وAudioClip.

اختُبر التقرير على عينة Android مرجعية غير مشفرة من Unity `2020.1.0a0`. أعاد التقرير 593 Asset Collection و374 Resource File و274,900 أصلًا مصنفًا، ولم تسجل عملية الاستيراد أي ملف معزول. تضم العينة 4,304 Mesh و4,185 Texture2D و1,563 AnimationClip و1,165 SkinnedMeshRenderer. هذا يؤكد عمل الجرد بعد استيراد مجموعة ملفات كبيرة؛ ولا يساوي ضمانًا بأن كل أصل في كل لعبة سيُصدر دون حالات خاصة.

### 2.5 التوثيق والاختبارات والحزمة

أضيفت وثيقتان: `PremiumSafeArchitecture.md` لتحديد المعمارية والحدود، و`PremiumPreviewWindowsUsage.md` لشرح تشغيل الحزمة التجريبية. كما أضيف مشروع `AssetRipper.Premium.Tests`، ويضم اختبارات للسياسة، ورفض الحالات المحظورة، وتقرير التشخيص، وملف الإعدادات. وقد اجتازت مجموعة Premium ثمانية اختبارات، واجتازت مجموعة الحل الكامل تسعة مشاريع اختبارات بإجمالي 517 اختبارًا ناجحًا.

## 3. ماذا عولج؟ وماذا لم يُعالج؟

عولجت **فجوات في سلامة سير العمل**، لا «ثغرات» يتم استغلالها. التحسينات الفعلية هي منع التشغيل غير المصرح به، ومنع محاولة التعامل مع صيغ محمية، والحفاظ على إعدادات تصدير أكثر محافظة على العلاقات، وإعطاء تقرير شفاف عندما تكون الملفات التابعة أو الموارد غير موجودة.

| المشكلة أو المخاطرة | المعالجة المنفذة | النتيجة العملية |
| --- | --- | --- |
| بدء معالجة بيانات دون تصريح صريح | فرض `--premium-authorized` | تتوقف عملية Premium قبل التحميل عند عدم التصريح |
| محاولة إدخال ملف مشفر أو حاوية غير قياسية | سياسة رفض مبكرة ومحددة السبب | لا توجد محاولة تحليل أو فك أو تخمين |
| احتمال فقد علاقات Prefab نتيجة إعدادات تصدير غير مناسبة | ملف استرداد محافظ على Prefab والمراجع المباشرة | نتيجة أوضح للبيانات القابلة للقراءة؛ ليس ضمانًا لبيانات ناقصة |
| صعوبة معرفة سبب فشل أو نقص الاستيراد | تقرير JSON منظم بعد الاستيراد | يمكن تمييز الموارد والملفات المعزولة وأصول الأولوية |
| تصدير محتوى غير قابل للقراءة كبديل غير صحيح | تعطيل `ExportUnreadableAssets` | لا ينشأ Mesh أو Texture أو Media مزيف |
| خلط Premium مع النسخة المفتوحة | مشروع تنفيذي ومكتبة واختبارات منفصلة | سلوك النسخة المفتوحة لا يتغير بهذه السياسة |

## 4. جانب الأمان: ما لم يتم فكّه أو تجاوزه

لا توجد «ثغرات تم فكها» في هذا المشروع. وبالتحديد، لم يُنفذ أي مما يأتي:

| المسار غير المسموح | الحالة | سبب الرفض |
| --- | --- | --- |
| فك تشفير AssetBundle أو ملف لعبة | غير منفذ ومرفوض | لا يعالج Premium إلا plaintext مصرحًا به |
| استخراج مفاتيح من اللعبة أو من الذاكرة | غير منفذ ومرفوض | لا يوجد تحليل ذاكرة أو سير عمل للمفاتيح |
| تفريغ ذاكرة عملية أثناء التشغيل | غير منفذ ومرفوض | ترفضه السياسة برمز `runtime-memory-not-supported` |
| تجاوز DRM أو anti-tamper أو anti-debug | غير منفذ ومرفوض | خارج نطاق المنتج بصورة صريحة |
| تحليل أو فك حاوية VFS خاصة | غير منفذ ومرفوض | ترفضه السياسة برمز `custom-vfs-not-supported` |
| تجاوز مصادقة، صلاحيات، أو مفاتيح وصول | غير منفذ ومرفوض | لا يوجد أي مسار لهذه العمليات |
| صنع Script أو Shader أو Media بديل عند غياب الأصل | غير منفذ | قد يكسر المراجع ويعطي نتيجة مضللة |

> النتيجة الصحيحة عند غياب اعتماد أو وجود محتوى محمي هي **تشخيص واضح**، لا محاولة تخمين أو تجاوز.

## 5. القيود الحالية التي يجب اختبارها لاحقًا

رغم نجاح البناء والاختبارات، ما زالت هناك تغطية عملية ناقصة تتطلب عينات مصرحًا بها من ألعاب أو مشاريع حقيقية. لم يُثبت بعد على عينات منفصلة فتح كل FBX ناتج في Blender، أو اكتمال SpriteAtlas، أو Audio/Video، أو Unity 5.x/2017/2018، أو Unity 6 وAddressables، أو المنصات غير Android. كما لا يمكن لأي سياسة أو إعداد تصدير استعادة بيانات لم تكن موجودة أصلًا في ملفات الإدخال.

المسار التالي الصحيح هو رفع عينات نصية ومصرح بها من ثلاث فئات: شخصية 3D قديمة مع عظام وحركات، حزمة Android متعددة الملفات مع كل الاعتمادات، وشخصية 3D حديثة من Unity 2021.3 أو 2022.3. تفاصيل الملفات المطلوبة ومعايير القبول موجودة في `PremiumTestCoverageReport.md`.
